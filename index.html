          🧠 Chip & GPU Guide — dedicated vs integrated, honestly

          The RTX tier changes everything for gaming and editing; the iGPU tier still rules battery life and weight.

          Dedicated (RTX) vs integrated (iGPU) — the real gap

          RTX 3050 6GBAspire 7 i7 / Core 7 — 1080p AAA at high/ultra, esports 144Hz-ready, CUDA + NVENC for editing
          RTX 3050 4GBIdeaPad Gaming 3 / Aspire 7 Core 5 — AAA medium-high
          RTX 2050 45WCyborg 15 — ≈ Radeon 680M in raster; DLSS tips it ahead
          —— the gap ——Everything below is integrated: fine for college, weak for modern games
          Radeon 680MSlim 3 15AHP10 — only if it says 7735HS
          Adreno X1-45Aspire 14 AI — fast, but Arm blocks many games
          Intel UHD 64EUAspire Lite i7 (i7-12650H)
          Intel UHD 48EUSlim 3 Intel · Motobook · Vivobook · V14 (13420H/Core 5 class)
          MX-class 2GBSlim 5i 15ITL05 — a 2021-tier dGPU; ≈ or below the 48EU tier today

          Windows-on-Arm: what runs on Snapdragon X

          • ✅ Native & fast: VS Code, Visual Studio, Python, Node.js, Java, Android Studio, browsers, MS Office, Spotify
          • ⚠️ Emulated via Prism — usually fine, occasionally slow: most other x86/x64 apps
          • ❌ Often blocked: anti-cheat games (Valorant), Docker x86 images, some pro video tools, older utilities & drivers

          Applies to Aspire 14 AI A14-11M and Slim 3 15Q8X10. List your course software + games and verify each before choosing Arm.

          ⚠️ The two standing traps

          • Slim 3 15AHP10: 7735HS → Radeon 680M. 7435HS → Radeon 610M (= Intel UHD class). Check the processor row.
          • ThinkBook 16 “Ryzen 5 220”: iGPU unconfirmed — get the full model code before trusting any spec.
